# EQDOM Client 360 Dashboard

Maquette HTML statique du dashboard EQDOM Client 360.

## Ouvrir directement

Ouvrir `dashboard/client360/index.html` dans un navigateur.

## Servir localement

Depuis la racine du projet :

```bash
python3 -m http.server 8080 -d dashboard/client360
```

Puis ouvrir :

```text
http://localhost:8080
```
